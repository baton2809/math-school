# Математика в картинках

Портал интерактивных моделей для индивидуальных занятий на планшете. Каждая тема — пять экранов, переключение кнопками «Назад / Дальше», вкладками или свайпом по рисунку.

| Тема | Модели для ученика | Для учителя |
| --- | --- | --- |
| Буквенные выражения, 5 класс | `/bukvennye-vyrazheniya/` | — |
| Пропорции, 6 класс | `/proporcii/` | `/proporcii/uchitel/` — карта темы |

Ссылка на конкретный экран: добавьте `#1`…`#5` в конец адреса.
