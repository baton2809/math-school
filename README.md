# Алгебра в картинках

Интерактивные модели для 5 класса (буквенные выражения): одна модель на экран, переключение кнопками «Назад / Дальше» или вкладками 1–5. Страница сделана под планшет, её можно открыть в любом браузере, установка не нужна.

1. Буква — это коробка (подобные слагаемые)
2. Вынесение за скобку как площадь
3. Текстовая задача в полосках
4. Задача-ловушка на ключевое слово
5. Вычитание через десяток

Ссылка на конкретное задание: добавьте `#1`…`#5` в конец адреса.
