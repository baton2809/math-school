Урок 1. Теорема Виета

Методичка для учителя: подготовка за 10 минут, лента времени, что говорить, задачи с ответами и где ждать ошибку. Внизу банк задач без ответов: 59 заданий по разделам.

Цель урока: ученик формулирует и доказывает теорему Виета, устно подбирает корни приведённого уравнения по обратной теореме, определяет знаки корней без решения, составляет уравнение по корням и находит значения выражений с корнями, не вычисляя сами корни.

Подготовка за 10 минут

  1. Пробежать ленту времени (2 мин).
  2. Листок разминки (блок 1) и пустая таблица из блока 2.
  3. Выбрать из банка задач 6–8 заданий на дом.
  4. Повторить про себя: теорема верна, только когда корни есть (D ≥ 0).

Три фразы урока

  • «Сумма корней равна второму коэффициенту с противоположным знаком, произведение — свободному члену».
  • «Подбор начинаем с произведения».
  • «Сначала убедись, что корни есть».

Главная мысль урока для учителя

Теорема Виета — это раскрытые скобки: (x − x₁)(x − x₂) = x² − (x₁ + x₂)x + x₁x₂. Если ученик это видит, ему не нужно запоминать, где минус: знак сам появляется при раскрытии скобок. Это связь с умножением многочленов из 7 класса, и доказательство занимает одну строку.

Три ошибки дают почти все промахи: забыт минус у суммы; теорема применена к неприведённому уравнению без деления на a; теорему «применяют», когда корней нет (x² + 2x + 5 = 0 «имеет сумму −2 и произведение 5», хотя корней нет). Поэтому в каждом блоке звучит вопрос «а корни есть?».

2. Открытие: что связывает корни и коэффициенты

Ученик сам замечает закономерность по таблице. Учитель не называет теорему, пока ученик не сформулирует гипотезу.

Заполним таблицу: корни, их сумма, их произведение. Посмотри на последние два столбца и на коэффициенты уравнения. Что замечаешь?

Уравнение вида x² + px + q = 0, где первый коэффициент равен 1, называют приведённым.

Проверь свою гипотезу на четвёртом уравнении, не решая его по формуле.

Ждите: «сумма равна p». Пусть сравнит знаки в первой строке: сумма 5, а p = −5. Формулировку «с противоположным знаком» ученик должен произнести сам.

0:22–0:3210 мин

3. Теорема и доказательство одной строкой

Сформулировать теорему, доказать через раскрытие скобок, перейти к неприведённому уравнению.

Сумма корней приведённого квадратного уравнения равна второму коэффициенту, взятому с противоположным знаком, а произведение корней равно свободному члену.

Почему? Если x₁ и x₂ — корни, то x² + px + q = (x − x₁)(x − x₂). Раскрой скобки, как в 7 классе, и сравни коэффициенты.

Если уравнение не приведённое, разделим его на a: x² + (b/a)x + c/a = 0.

Важно: всё это имеет смысл, только если корни существуют. Сначала D ≥ 0.

  1. Не решая, найдите сумму и произведение корней: x² − 9x + 14 = 0. 9; 14
  2. x² + 4x − 21 = 0 −4; −21
  3. 3x² − 6x − 2 = 0 D = 60 > 0; 2 и −2/3
  4. x² + 2x + 5 = 0 D = −16 < 0, корней нет

Задача 4 — специально. Почти все ответят «−2 и 5». Это хороший момент: «Найди эти корни». Корней нет — значит, и говорить об их сумме бессмысленно.

5. Обратная теорема и подбор корней устно

Научить подбирать корни приведённого уравнения за 10–20 секунд и определять знаки корней без решения.

Обратная теорема: если числа m и n таковы, что m + n = −p и m · n = q, то m и n — корни уравнения x² + px + q = 0.

Подбирать удобнее с произведения: делителей у q немного. Переберём пары множителей и посмотрим, у какой нужная сумма.

Знаки: если q > 0, корни одного знака, и этот знак как у суммы −p. Если q < 0, корни разных знаков, и больший по модулю имеет знак суммы −p.

  1. x² − 7x + 12 = 0 3; 4
  2. x² + 8x + 15 = 0 −3; −5
  3. x² − 2x − 24 = 0 6; −4
  4. x² + 5x − 14 = 0 2; −7
  5. x² − 11x + 30 = 0 5; 6
  6. x² − x − 56 = 0 8; −7
  7. Не решая, определите знаки корней: x² + 9x + 14 = 0; x² − 3x − 40 = 0. оба отрицательные; разных знаков, положительный больше по модулю

Ждите: в задаче 3 ответ «−6 и 4». Произведение подходит, а сумма −2, а нужно +2. Правило: подобрал — проверь сумму и произведение вслух.

6. Применения: второй корень, коэффициент, уравнение по корням

Использовать теорему как инструмент, когда известна часть данных.

Один корень известен. Что проще найти второй: через сумму или через произведение? Через то, где неизвестный коэффициент не участвует.

Чтобы составить уравнение по корням, нужно сложить корни и перемножить их: x² − (сумма)x + произведение = 0.

  1. Один из корней уравнения x² + px − 18 = 0 равен 3. Найдите другой корень и p. x₂ = −6, p = 3
  2. Один из корней уравнения 5x² − 12x + c = 0 равен 2. Найдите другой корень и c. x₂ = 0,4, c = 4
  3. Составьте приведённое квадратное уравнение с корнями 2 и −5. x² + 3x − 10 = 0
  4. Составьте уравнение с целыми коэффициентами, корни которого 1/2 и 3. 2x² − 7x + 3 = 0
  5. В уравнении x² − 8x + q = 0 один корень в 3 раза больше другого. Найдите корни и q. 2 и 6; q = 12

Ждите в задаче 3: x² + 3x + 10 или x² − 3x − 10 — путаница со знаком суммы. Проверка обратной теоремой: подставить 2 в полученное уравнение.

7. Выражения с корнями без нахождения корней

Выразить через сумму и произведение то, что нельзя посчитать «в лоб» из-за неудобных корней.

У уравнения x² − 6x + 4 = 0 корни 3 ± √5, считать неудобно. Но сумма 6, а произведение 4 — это всё, что нам нужно.

x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂. Откуда это? Из квадрата суммы, 7 класс.

  1. Для x² − 6x + 4 = 0 найдите x₁² + x₂². 36 − 8 = 28
  2. 1/x₁ + 1/x₂ (x₁ + x₂)/(x₁x₂) = 6/4 = 1,5
  3. (x₁ − x₂)² 36 − 16 = 20
  4. x₁²x₂ + x₁x₂² x₁x₂(x₁ + x₂) = 24

Ждите: x₁² + x₂² = (x₁ + x₂)² = 36. Попросите проверить на простом уравнении x² − 3x + 2 = 0 с корнями 1 и 2: 1 + 4 = 5, а не 9.

8. Самостоятельная работа: три уровня

  1. А. Подберите корни: x² − 9x + 20 = 0; x² + 3x − 18 = 0. 4 и 5; 3 и −6
  2. Б. Один из корней уравнения x² − 13x + q = 0 равен 4. Найдите второй корень и q. 9; q = 36
  3. В. Не решая уравнение x² + 5x − 3 = 0, найдите x₁² + x₂². 25 + 6 = 31

В задаче В частая ошибка: 25 − 6 = 19 (минус на минус). Произведение −3, значит −2 · (−3) = +6.

9. Итог и проверка на выходе

  1. Составьте приведённое уравнение с корнями −2 и 7. x² − 5x − 14 = 0
  2. Не решая, найдите сумму и произведение корней 2x² − 10x + 3 = 0. D = 76 > 0; 5 и 1,5
